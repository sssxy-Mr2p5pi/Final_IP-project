# 手写字体与交互样页

2026-10-20 更新。此目录是独立技术预览，用于比较字体、局部墨迹效果和界面交互。正式剧情尚未接入。

## 打开

双击 `index.html`，使用 Chrome 或 Edge。移动样页时复制整个 `ui-study` 文件夹。运行时无网络依赖。顶部模式控件和底部技术说明属于预览工具。

## 字体分配

| 区域 | 字体 |
|---|---|
| Thinking 标题及短句 | Rock Salt |
| Self 标题及自述 | Caveat |
| Terminal、长正文、Reports、Crew log、Camera 标签 | Kalam |
| Diary 测试短句 | Reenie Beanie |
| 外部预览工具及小号标识 | 原有 Barlow |

Thinking 内的操作短语使用 Kalam，与短句区分。长文模式统一采用 Kalam 22px、1.6 倍行距。日记仅展示草案已有短句，并标注字体测试；它不代表已经创作或保存了一篇日记。

四款新增字体来自 Google Fonts 官方仓库的固定提交，文件随样页保存。Rock Salt 使用 Apache 2.0，其余三款使用 SIL OFL 1.1。原始许可在 `fonts/`，来源、版本和 SHA-256 在 `sources.json`，英文说明在 `CREDITS.txt`。

## 可以操作的内容

| 操作 | 结果 |
|---|---|
| Clean | 清晰字形，关闭晕染、碎屑与重复动画。 |
| Ink | 静态墨迹、晕染和局部擦除，点击也不播放动画。 |
| Local motion | 默认模式，每隔约 4–6 秒最多两个指定词抖动约 0.3 秒。 |
| 点击 fine、moving、Two of them | 选中反馈；动态模式下，墨迹碎屑向外散开约 0.7 秒。原词可读，点击区域保持原位。 |
| Long text | 约 2,040 词的重复阅读夹具，暂停文字动画。 |
| Camera | 进入左侧四格摄像头、右侧 Thinking 的临时布局。 |
| 点击摄像头画面 | 切换选中边框；画面采用现有两张占位图重复排列。 |
| Return to Self／浏览器返回和前进 | 在两种视图之间往返。Thinking 仍为同一阅读区，保留滚动偏移，不追加解说。 |
| Terminal | 打开连词成句抽屉。依次点击词块添加，点击已选词移除，左右箭头调整顺序，Clear 清空。 |
| Pending、Reports、Diary、Crew log | 打开各自的文字抽屉。每次只打开一个抽屉。 |
| 再次点击当前入口／Esc | 关闭抽屉；Esc 把键盘焦点还给入口。 |

词块来自已有句子 `They still talk to me.`。词块每次只能选入一次；移动到句首或句尾后，对应方向箭头禁用。选词、移除和重排会把焦点移至相关词，支持 Tab、Enter 和空格操作。

关闭抽屉或切换 Camera 时，成句内容保留在当前页面内；刷新后清空。样页只展示拼接结果，没有语法判断、报告发送、日记保存或剧情结果。

抽屉占据独立布局行，最多半屏，为 Thinking 保留至少两行正文空间。内容较多时，各阅读区、摄像头区和成句区可以独立滚动。

## 动效与离线实现

- 大部分文字保持稳定。抖动仅影响字形内层，位移约 1–2px。
- 墨迹散开使用三层固定的文字副本和点状 SVG 遮罩；快速重复点击复用这些层，重新播放当前效果，不追加粒子节点。
- 装饰副本从辅助技术中隐藏，不接收点击。原始文字始终保留。
- 浏览器在 file:// 下会拦截外部 CSS 遮罩读取，因此 `ink-fragments.svg` 以 data URL 嵌入 CSS；原始文件保留供核对。
- 系统启用减少动画时，保留静态墨迹并停止动态效果。长文模式和后台页面也停止动态效果。
- 样式限定在 `.ui-study` 容器内。Camera 使用同页 hash 链接，支持离线地址及原生浏览器历史。

## 修改入口

| 文件 | 职责 |
|---|---|
| index.html | 页面结构、短句、Camera 图像及抽屉入口 |
| study.css | 字体、布局、晕染、抖动和碎屑效果 |
| study.js | 视图切换、抽屉、词块排列及动画调度 |
| fonts、assets | 本地字体、许可、两张摄像头夹具及程序纹理 |
| sources.json、CREDITS.txt | 素材来源与校验记录 |
| verify.cjs | 离线浏览器行为检查 |

调整文字时同步装饰用的 `data-echo`。碎屑副本在初始化时读取实际词语；词块测试数组位于 `study.js` 的 `tokens`。以后迁移至 Harlowe 时，交互需要接入现有唯一故事源。

## 验证

从工程目录执行 `node art/ui-study/verify.cjs`。实际机器结果见 `../../evidence/tests/ui-study.json`，截图在 `../../evidence/tests/screenshots/ui-study/`。

检查覆盖 Chrome、Edge 的 1920×1080、1366×768、800×600，包含字体分配和本地加载、动画点击区域、减少动画、五个抽屉、词块操作、Camera 往返及长文滚动。后台暂停通过受控的可见性事件模拟检查，真实切换到其他应用的体验另留人工核验。

最新结果以 JSON 与本轮工作记录为准。字体偏好、动效舒适度、真实后台切换和另一台电脑运行继续由人工核验；样页测试不代表正式剧情已完成。

## 本轮边界

当前变化仅在独立样页及配套文档中。正式 Harlowe 源码、运行包和设定稿保持原样。摄像头四格布局是临时试排，正式画面形式待定；没有新增自动思考、预测、语音、报告发送或日记保存机制。
