# 字体与手绘质感样页

2026-10-20。此目录为独立视觉测试，依据作者的两张手稿及《UI 设计草案》制作。用于选择字体、文字效果和布局；正式故事尚未接入。

## 打开与体验

双击 [index.html](index.html)，使用 Chrome 或 Edge 打开。所有字体、图片和脚本已放在目录内，运行不需要联网，也不需要启动服务。转移到其他位置时，复制整个 `ui-study` 文件夹。

顶部为画面外的预览工具，底部为测试说明；这些内容不属于正式游戏界面。

| 操作 | 可以看到的结果 |
|---|---|
| `Clean` | 清晰字形，关闭重影、擦除和重复动画；保留四区结构。 |
| `Ink` | 静态重影与局部擦除，保留纸面质感。 |
| `Local motion` | 默认模式。每隔约 4–6 秒，至多两个词短暂变化约 0.3 秒，位移不超过 2px。 |
| 点击带下划线的词 | 切换选中状态与墨迹表现，点击区域保持原位。再次点击恢复。 |
| 点击 `Pending`、`Reports`、`Diary`、`Crew log` | 打开或切换下方抽屉。再次点击当前入口关闭，按 Esc 也可关闭。 |
| `Long text` | 切换到约 2,040 词的重复测试文本，在 Thinking 内滚动阅读；此模式暂停局部词动画。 |
| Tab、Enter 或空格 | 移动焦点并操作文字入口；Esc 关闭抽屉并把焦点还给入口。 |

系统启用“减少动画”时，`Local motion` 自动保留静态墨迹并停止跳动，页面底部显示对应状态。离开当前浏览器标签页时暂停重复动画。

`Diary` 抽屉故意为空，符合草案中的初始状态；它没有编辑或保存功能。`Take another look` 和 `Leave it` 在本样页只演示文字选中效果，不执行预测，也不改变任何结局。

## 当前设计

- Self 和 Camera 共占左侧约 30%；Thinking 位于右侧；Terminal 固定在画面底部。
- Barlow Regular 用于正文，Barlow SemiBold 用于强调，Barlow Condensed Bold 用于标题。正文基准为 22px、1.6 倍行距。
- 纸面由静态 SVG 噪声绘制，边框由轻微不齐的矢量路径绘制。字形以局部透明度、遮罩、重影与 SVG 位移滤镜处理。
- 所有样式限定在 `.ui-study` 容器内。装饰层不接收点击；动效仅作用于字形内层，不改变外层文字入口的位置。
- 正文使用草案已有英文句子。重复文本只作排版检查，不构成新增故事。
- Camera 是现有工程几何占位图的副本，采用灰度显示；未制作正式场景美术。

## 文件与调整位置

| 文件 | 用途 |
|---|---|
| `index.html` | 四区布局、短文本和可点击词。 |
| `study.css` | 纸面颜色、字体、边框、响应式布局及局部动效。 |
| `study.js` | 模式切换、抽屉、长文本与动画节奏；无故事状态、存档或网络请求。 |
| `fonts/` | 三份本地字体及原始许可证。 |
| `assets/` | 纸面、边框和摄像头占位图。 |
| `sources.json`、`CREDITS.txt` | 来源、许可、用途、版本及校验记录。 |
| `verify.cjs` | 使用项目已有 Playwright 完成本机离线检查。 |

调整字体尺寸与颜色时修改 `study.css`。`fx-echo` 表示重影，`fx-dust` 表示局部擦除；`data-motion-word` 标记参与轮流跳动的词。复制这类词时，同步修改实际文字和 `data-echo`，后者只用于装饰副本。

所有带 `word-control` 的文字入口只切换视觉状态。当前样页没有 Harlowe 运行时，后续移植时需用现有故事源中的 Harlowe 交互接管这些入口；这份样页不能直接当作 Twine 故事导入。

## 已执行的检查

2026-10-20，本机 Chrome 与 Edge 分别在 1920×1080、1366×768、800×600 下完成六组检查：

- 浏览器离线模式通过本地文件地址打开，三份字体及图片完整加载，无远程请求和页面脚本错误。
- 窗口内无横向溢出；三种模式可切换；动态字形和选中状态不推挤相邻段落。
- 记录实际动画期间的活动词数量与点击框位置，最多两个词动画、点击框不移动。
- 鼠标和键盘可操作文字，装饰层不拦截事件。
- 四个抽屉均可打开和关闭；高度不超过半屏；Thinking 保留至少两行正文空间，阅读区域不被抽屉覆盖。
- 减少动画设置生效，并保留静态重影；长文本可以滚动到末尾，展开抽屉后仍保留阅读空间。
- 可见内容为英文。

机器结果见 [ui-study.json](../../evidence/tests/ui-study.json)。每组保存正常、动态、选中、抽屉和长文本截图，位置为 `evidence/tests/screenshots/ui-study/`，截图按项目既有规则排除出 Git。

已查看正常首屏、小窗口抽屉和长文本截图，确认标题、正文和抽屉的阅读关系。墨迹强度、字体偏好和动态舒适度仍由作者实际体验决定。另一台电脑尚未验证；本轮检查也不代表 Harlowe 集成已经完成。

复查时在工程目录执行：

```text
node art/ui-study/verify.cjs
```

首次受限环境内的 Edge 启动失败，随后使用独立临时浏览器配置在限制外完成六组检查。未改动浏览器的用户配置。
