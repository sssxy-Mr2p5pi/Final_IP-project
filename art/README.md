# Blender 工作约定

正式模型与场景由组员手工制作，或使用许可允许的第三方素材。禁止外包建模。
在此保存小型 .blend 工程；依赖贴图需打包或使用相对路径，并在来源清单登记。
单个资产较大时先讨论 Git LFS 或外部存储，避免直接提交大型二进制文件。工具安装与渲染缓存留在仓库外版本范围。
建议先做同一房间两个视角，以1280×720输出PNG。记录手工制作、镜头调整与渲染分别耗时。
本轮默认立方体检查只用于验证Blender环境，其工程和渲染图位于本地 evidence/environment/blender-smoke。

## 故事骨架素材（2026-10-28）

assets/images/skeleton 是按场次与用途命名的几何占位，均为开发夹具。替换入口见各场 Media 节点。assets/fonts 复用 ui-study 的手写字体并附许可与来源，中文提纲使用系统中文字体。

art/ui-study 仍是独立样页；运行故事的样式和脚本统一维护在 src/story.twee。本轮未生成正式美术。
