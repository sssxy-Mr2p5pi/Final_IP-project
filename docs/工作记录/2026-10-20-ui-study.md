# 2026-10-20 字体与动效样页

依据作者已确认的《硬朗字体与手绘质感 UI 样页》方案，完成 `art/ui-study/` 独立离线预览。

## 完成内容

- 四区布局、浅纸色背景、程序绘制边框与纸纹。
- 从字体作者仓库取得三份 Barlow 字体，固定提交版本，记录下载来源、许可证和 SHA-256。
- Clean、Ink、Local motion 三种对照；局部重影、擦除、短暂跳动；动效不改变文字入口位置。
- 四个抽屉的开合与键盘操作；Thinking 保留阅读空间；约 2,040 词的重复文本样本。
- 中文操作说明、英文来源说明与独立检查入口。

## 实际验证

本机 Chrome、Edge 各三种窗口（1920×1080、1366×768、800×600），六组检查通过。使用离线浏览器上下文和本地文件地址，未发生远程请求，字体和占位图完整加载。

核对动画活动词上限、点击框稳定性、鼠标与键盘操作、减少动画、抽屉尺寸与遮挡、长文本滚动，以及可见文字语言。结果保存在 `evidence/tests/ui-study.json`，30 张检查截图位于本机忽略目录。

首轮检查调整了减少动画事件的异步等待方式。受限环境中的 Edge 启动失败；随后在限制外使用独立临时配置完成验证，没有修改用户浏览器配置。正常首屏、小窗口抽屉及长文本截图已经查看。
