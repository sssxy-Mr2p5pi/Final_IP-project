## 发现及修复

1. 文件下载在受限环境中触发 WinError 10013，随后通过授权网络访问取得官方文件。
2. CSS 外部 SVG 遮罩在 file:// 下加载失败。将同一 SVG 以 data URL 嵌入 CSS，保留原文件与字节一致性检查，重新验证无资源加载失败。
3. Edge 在受限环境中因命名管道错误无法启动。随后使用临时浏览器配置完成六组检查；未读取或修改用户日常浏览器配置。
4. 曾因检查命令的工作目录重复拼接，导致新版检查文件写入失败；该次执行旧检查产生字体数量断言失败。修正路径和检查后重新完成验证。
