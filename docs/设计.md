# 设计

## 数据与运行过程

作者在 Twine 修改节点 → 导出单份 Twee 源 → Tweego 使用本地 Harlowe 编译 → 拷贝白名单素材 → 浏览器通过 file:// 运行。
Twee 的 StoryData 固定格式版本和 IFID。正式文字节点使用 author-text 标签；技术代码集中在 script 与 stylesheet 节点。
正文交接检查比较标签节点的内容指纹，归一化 CRLF 并去除外围空白；它无法判断人工贡献，也不监控 Twine 尚未导出的内容。

## 交互模块

Harlowe 管理视角和当前状态；choice 使用空字符串、A、B。StoryInit 使用 startup 标签初始化变量。Controls 用 link-repeat、set 和 replace 宏修改选择并刷新显示。
Reader 使用 display 宏渲染 TextShort、TextLong；原生 dialog 按点击显示对应段落。正文中的顶层宏在进入视角时执行，改变剧情状态的宏需放入明确的点击事件。
原生 dialog 管理模态层、键盘焦点和 Escape。字体范围为 16–28px，由页面脚本维护阅读字号。底层画面采用固定 16:9 比例，热点使用相对位置。
单个 Audio 实例共享于视角之间；播放请求有并发保护，停止会使未完成请求失效。失败在界面显示英文提示，允许再次播放。
Start 不自动播放声音。Restart 使用 Harlowe 重新开始机制清空状态并停止音频。

## 接口和替换

图片接口为 1280×720 的固定视角图。替换图像时保留素材路径，按目标位置调整对应热点百分比。
assets/manifest.json 记录每个运行素材的 path、author、source、license、modifications 和 use。构建只拷贝清单所列资产。
运行包白名单为编译 HTML、英文说明、来源说明及登记素材。构建输出与 ZIP 排除出 Git。
默认场景渲染检查独立于游戏图像，未来 Blender 渲染图和 2D 图均通过同一图片接口接入。

## 工程约束

本地工具目录排除出 Git，版本和下载指纹进入 tools.lock.json。Playwright 仅用于开发测试，运行包无需它。
不安装后端服务。浏览器运行时不请求远程字体、脚本或 API。Windows 系统字体回退不依赖下载。
采用轻量需求与验收维护；本轮不配置规格冻结、审批 Hook 或自定义代理技能。

## 编辑器与离线预览

Harlowe 从官方 Twine 的 app.asar 提取，校验值固定在 tools.lock.json。旧格式不再参与构建。
构建同时复制登记素材到 .local/twine-scratch 和 .local/twine-library，解决 Twine Play 的相对路径定位。
故事源和编辑器副本仍通过显式导出/导入交接，构建只同步素材，不覆盖作者编辑器故事。
Harlowe 的 tw-link 补充 link 角色，便于键盘和辅助技术识别。
Harlowe 同一标签页可恢复进度；独立运行验证使用新标签页，重新开始使用 restart 宏。

## 独立手写样页（2026-10-20）

`art/ui-study/` 保持为独立 HTML/CSS/JavaScript 预览。Camera 通过 `#camera` 与 `#self` 切换同页布局，主阅读元素保持不变，记录并恢复滚动偏移。摄像头区域临时采用 60%/40% 左右分栏，两张现有诊断图复用为四格画面。

Terminal 与四个资料入口共用单个抽屉，抽屉占据独立布局行。成句以已有句子的词序数组表示，仅存于页面内存。点击词添加或移除，左右控件交换相邻词，结果固定在成句区底部；不写入存储，也不触发故事动作。

字体文件保留原始格式和许可，来源版本与校验值登记在样页 sources.json。晕染使用轻微文字阴影及 SVG 模糊，碎屑使用三层固定装饰副本；点状 SVG 遮罩嵌入 CSS，避免 file:// 外部遮罩限制。装饰内容不进入辅助阅读树，也不接收点击。快速重复点击复用同一组动画层。

减少动画、长文模式、页面隐藏和效果模式切换均取消动态效果。Harlowe 故事源和正式素材清单不引用此样页。
